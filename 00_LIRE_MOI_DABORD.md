↓
Événement ajouté à la BD et visible dans le tableau

```
Cliquer sur un événement
↓
Le formulaire se remplit automatiquement
↓
Modifier les champs
↓
Cliquer "✏️ Modifier"
↓
Mis à jour instantanément
```

### ✅ Supprimer un Événement
```
Cliquer sur un événement
↓
Cliquer "🗑️ Supprimer"
↓
Confirmer la suppression
↓
Événement supprimé de la BD
```

## 🎓 Architecture Simplifiée

```
┌─────────────────┐
│   Main.java     │ ← Vous lancez ici
│ (Application)   │
└────────┬────────┘
         │
         ↓
┌─────────────────────────────┐
│   EvenementView.fxml        │ ← Interface graphique
│   (Formulaire + Tableau)    │
└────────┬────────────────────┘
         │
         ↓
┌──────────────────────────────┐
│ EvenementController.java     │ ← Gère vos clics
│ (Add/Edit/Delete/Search)     │
└────────┬─────────────────────┘
         │
         ↓
┌──────────────────────────────┐
│ EvenementService.java        │ ← Modifie la BD
│ (CRUD vers MySQL)            │
└────────┬─────────────────────┘
         │
         ↓
┌──────────────────────────────┐
│ MySQL boostup                │ ← Votre data
│ (Table evenement)            │
└──────────────────────────────┘
```
