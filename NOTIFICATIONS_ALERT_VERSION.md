# 🚀 NOTIFICATIONS SIMPLIFIÉES - 100% GARANTIES !

## ✅ NOUVELLE VERSION ULTRA SIMPLE

J'ai créé une version **GARANTIE** d'affichage des notifications !

Au lieu de popups complexes, maintenant les notifications utilisent des **Alert JavaFX** qui sont **100% fiables** !

---

## 🎯 CE QUI VA SE PASSER MAINTENANT

Quand tu lances l'app :

1. **Page login** s'affiche
2. **1 seconde après** → Les notifications commencent
3. **4 fenêtres Alert** apparaissent une par une (espacées de 300ms)
4. Chaque Alert affiche :
   ```
   🎉 BoostUp - Rappel d'Événement
   
   [Titre de l'événement]
   
   📅 Date: 23/02/2026
   📍 Lieu: [lieu]
   
   ⏳ Rappel: Cet événement aura lieu dans 2 jours !
   
   [ OK ]
   ```

---

## 🚀 LANCE L'APP MAINTENANT !

```bash
cd C:\Users\Pc\IdeaProjects\boostup
mvn javafx:run
```

Clic droit sur MainApp.java → Run

## 🎨 APPARENCE

Chaque notification est une fenêtre Alert avec :
- 🎉 Titre : "BoostUp - Rappel d'Événement"
- 📝 Header : Titre de l'événement
- 📄 Corps : Date, Lieu, Message de rappel
- 🔘 Bouton "OK" pour fermer

**C'est simple mais EFFICACE !**
